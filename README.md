# Simple Calculator

A beginner-friendly calculator built with **HTML, CSS and vanilla JavaScript**.

## Features
- Addition, subtraction, multiplication, and division.
- Clear and delete controls.
- Responsive layout.

## Run locally
1. Clone or download this repository.
2. Open `index.html` in your browser.

No installation or build tools are required.

## Files
- `index.html` — calculator interface
- `style.css` — calculator layout
- `script.js` — calculator logic

## What this project practises
Handling button events, working with numbers, and organising simple application logic.
